10. Описание API

Клиентское приложение взаимодействует с системой через HTTP API.
Предполагаются следующие основные точки входа.

| Метод | Адрес | Назначение |
|---|---|---|
| GET | `/api/events` | Получение каталога мероприятий |
| GET | `/api/events/{id}` | Получение информации о мероприятии |
| POST | `/api/registrations` | Регистрация на мероприятие |
| DELETE | `/api/registrations/{id}` | Отмена регистрации |
| GET | `/api/tickets/{id}` | Получение билета (с QR-кодом) |
| POST | `/api/tickets/check-in` | Отметка о посещении (валидация QR) |
