## Конфликт

После ручного объединения смыслов файл зафиксирован в `2c610d5`, использованный stash удалён. Это учебное воспроизведение, не работа двух реальных участников.

## Проверка и вывод

`git check-ignore -v` подтвердил правила для примеров `bin`, `obj`, `.env` и SQLite; `git ls-files` не нашёл отслеживаемых `bin` или `obj`. Граф проверен командой `git log --oneline --graph --decorate --all`. Исходный код не изменялся и решения ещё не было, поэтому сборка и тесты не запускались. Секреты в истории нельзя защитить задним числом только через `.gitignore`: их следует отозвать и заменить.
