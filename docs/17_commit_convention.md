17. Правила коммитов

Используются обозначения:

- feat: новая функциональность
- fix: исправление
- docs: документация
- test: тесты
- refactor: изменение структуры кода
- chore: техническое изменение

Примеры:
- docs: describe event management scope
- feat: add registration DTOs
- test: add capacity validation tests
