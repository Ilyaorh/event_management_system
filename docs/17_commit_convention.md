# Правила коммитов

Коммит содержит одно логически связанное изменение; сообщение кратко описывает выполненное действие. В текущей работе используются русские сообщения в начальной форме глагола, например:

```text
Добавить проверку свободных мест
Уточнить контракт выпуска билета
Покрыть отмену регистрации тестами
```

В старой истории могут встречаться английские сообщения и префиксы `feat`, `fix`, `docs`, `test`, `refactor`, `chore`. Их история не переписывается.
