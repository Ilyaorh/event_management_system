13. Общий сценарий создания регистрации
После определения протоколов полный процесс регистрации выглядит следующим образом:

Клиент
   │
   │ Регистрируется на мероприятие
   ▼
 ApiHost
   │
   ▼
 RegistrationModule
   │
   ├──────────────► UserModule
   │                 Проверка существования пользователя
   │
   ├──────────────► EventModule
   │                 Проверка мест и резервирование
   │
   │ Создание Registration
   │
   └──────────────► TicketModule
                     Генерация билета и QR-кода

Результатом операции является созданная регистрация с зарезервированным местом и выпущенным билетом.
