4. Перечень модулей системы
В проекте выделено четыре основных функциональных модуля.

| Модуль | Ответственность |
|---|---|
| EventModule | Хранение информации о мероприятиях, управление лимитами мест |
| RegistrationModule | Создание и управление регистрациями участников |
| UserModule | Хранение информации о пользователях и их ролях |
| TicketModule | Генерация уникальных билетов и валидация при check-in |

Дополнительно используется `ApiHost`, который принимает запросы от пользовательского интерфейса и передает их соответствующим модулям.

4.1. EventModule
Отвечает за каталог и управление мероприятиями.
Основные функции:
- получение списка мероприятий;
- получение информации о мероприятии;
- проверка наличия свободных мест;
- резервирование места;
- снятие резерва (при отмене регистрации);
- изменение статуса мероприятия (Отменено, Завершено).

Пример состояний мероприятия:
- Draft
- Published
- Cancelled
- Completed

4.2. RegistrationModule
Отвечает за процесс регистрации.
Основные функции:
- создание регистрации;
- проверка дубликатов;
- отмена регистрации;
- получение списка регистраций пользователя.

Модуль взаимодействует с:
- EventModule
- UserModule
- TicketModule

4.3. TicketModule
Отвечает за выпуск и проверку билетов.
Основные функции:
- генерация уникального кода билета;
- создание QR-кода;
- проверка валидности билета;
- отметка о посещении (check-in).

Пример состояний билета:
- Active
- Used (Check-in passed)
- Cancelled

4.4. UserModule
Отвечает за работу с пользователями.
Основные функции:
- регистрация пользователя;
- получение данных профиля;
- управление ролями (Участник, Организатор).
