15.1. Модульные тесты

Примеры:

- Тест 1: Свободные места есть. Ожидается: резервирование успешно.
- Тест 2: Мест нет (EVENT_FULL). Ожидается: отказ в резервировании.
- Тест 3: Пользователь уже зарегистрирован. Ожидается: отказ (защита от дубликатов).
- Тест 4: Мероприятие отменено. Ожидается: отказ (EVENT_CANCELLED).

15.2. Интеграционные тесты

Сценарий 1. Успешная регистрация.

- Ожидается: место зарезервировано, регистрация создана, билет выпущен.

Сценарий 2. Отмена регистрации.

- Ожидается: статус регистрации изменен на Cancelled, место возвращено в EventModule, билет деактивирован.

15.3. Проверка сборки

После внесения изменений должны выполняться:
- dotnet build
- dotnet test
