16. Правила ведения репозитория
Для проекта используются следующие основные ветки:
- main (стабильная версия)
- develop (интеграция)
- feature/* (новые функции, например: feature/event-catalog, feature/qr-generation)
- fix/* (исправления, например: fix/capacity-race-condition)
- docs/* (документация)
