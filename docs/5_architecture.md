5. Архитектурная схема

Для проекта выбрана модульная архитектура.

                          ┌──────────────────┐
                          │      Клиент      │
                          └────────┬─────────┘
                                   │
                                   │ HTTP
                                   ▼
                          ┌──────────────────┐
                          │     ApiHost      │
                          │ ASP.NET Core API │
                          └────────┬─────────┘
                                   │
                  ┌────────────────┼─────────────────┐
                  │                │                 │
                  ▼                ▼                 ▼
         ┌────────────────┐ ┌───────────────┐ ┌────────────────┐
         │ Registration   │ │  UserModule   │ │  EventModule   │
         │    Module      │ └───────────────┘ └───────▲────────┘
         └───────┬────────┘                           │
                 │ резервирование места               │
                 └────────────────────────────────────┘
                 │
                 │ генерация билета
                 ▼
         ┌────────────────┐
         │  TicketModule  │
         └────────────────┘

Центральным модулем бизнес-процесса является `RegistrationModule`.
При регистрации на мероприятие он:
- получает данные пользователя;
- проверяет наличие свободных мест;
- резервирует место;
- создает запись о регистрации;
- передает информацию в модуль билетов для генерации QR-кода.
