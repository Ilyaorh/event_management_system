# Event management system

Учебный ASP.NET Core API для создания мероприятий, регистрации участников и выпуска билетов с QR-кодами. Каталог и результаты регистрации хранятся в SQLite.

> Важно: в этой версии **нет входа и проверки прав**. Идентификатор участника не подтверждает личность, а билет можно получить по идентификатору через API. Запускайте проект только локально на учебных данных; для открытого доступа он не предназначен.

## Требования и запуск

Нужны Git, .NET SDK 9 и доступ к NuGet при первом восстановлении. Версия платформы выбрана для задания; перед дальнейшей эксплуатацией проверьте срок поддержки .NET 9.

```bash
git clone https://github.com/Ilyaorh/event_management_system.git
cd event_management_system
dotnet restore
dotnet build
dotnet test
dotnet run --project src/EventManagement.Api --urls http://127.0.0.1:5090
```

В другом окне Git Bash: `curl http://127.0.0.1:5090/health`. Примеры создания мероприятия, участника и регистрации - в [описании API](docs/api.md).

Файл `events.db` создаётся в текущей директории и исключён из Git. При необходимости путь можно задать через `ConnectionStrings__Events`, например `Data Source=local-events.db`. Схема создаётся автоматически через `EnsureCreated`; миграции схемы пока не реализованы, поэтому проект не следует использовать для ценных данных.

## Возможности и ограничения

- Создание и просмотр мероприятия; добавление участника.
- Регистрация с проверкой свободных мест и повторов, выпуск QR-билета; отмена с возвратом места.
- Однократный check-in по коду билета; отмена после check-in запрещена.
- Нет редактирования/отмены мероприятия, истории пользователя, ролевой модели, платежей, email и пользовательского веб-интерфейса. Первоначальные документы содержат более широкий план, а не список готовых функций.
